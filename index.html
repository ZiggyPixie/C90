Chart range notes

    Check against the AFM worked examples computed live

    Each chart's printed example run through this calculator. Ground rolls, accelerate-stop and climb values land within about 1% of the book. The over-obstacle distances come out 1–3% below the printed examples, because the examples in the AFM do not track their own guide lines exactly. Interpolating the guide lines the way a pilot would by hand gives the numbers shown. If you want the book-example level of conservatism, add a 3–5% margin above.

    How this works

    The curves on each AFM chart were digitized from the supplement and are interpolated the same way you would read the chart: pressure altitude and OAT give a reference value, which is carried along the weight, wind and obstacle guide lines. Pressure altitude is field elevation plus 1,000 ft per inHg below 29.92.

    Green means inside the charted data. Amber means the inputs fall slightly outside a curve and the value is extrapolated. Red means the condition is beyond the chart (for example hotter than the ISA+37 °C limit), and no value is given.

    Headwind is entered positive and tailwind negative; the charts already include the regulatory wind factors. Obstacle guide lines are only valid at the end heights, so only the 0 ft and 35/50 ft values are given.

    This is a planning aid built from digitized charts. It does not replace the AFM, the basic Beechcraft POH, or the Blackhawk supplement. Verify critical numbers against the book.
